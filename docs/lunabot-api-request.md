# LunaBOT 共同開発のお願い：ご当地めし帖との連携API

## 背景
「ご当地めし帖」は、都道府県・市区町村ごとに、サーバーのみんなのおすすめ飯を共有するサイトです（Discordログイン、地図、口コミ、お気に入り付き）。
LunaBOT と連携して、サーバーの中でも使えるようにしたいです。BOTのトークンはサイト側に渡さず、**BOT側に小さなAPIを足してもらう**形でお願いします。

## 連携の方針
- 認証は、共有シークレットによる署名（HMAC-SHA256）。トークンやチャンネルIDは、サイト側に渡しません。
- 宛先のチャンネルやロールは、BOT側の設定で固定し、リクエストからは指定させません。
- すべて「サイト → BOT」のサーバー間通信です（ユーザーのブラウザからは呼ばない）。

### 共通の署名ルール
リクエストヘッダー
- `X-Timestamp`: 送信時刻（ミリ秒）。60秒を超えて古いものは拒否
- `X-Signature`: `HMAC-SHA256(secret, X-Timestamp + "." + リクエスト本文)` の16進文字列。一致しなければ 401
- 同じ署名の再送は 409（リプレイ対策）

## 欲しいAPI（優先度順）

### 1. 新着お店の通知（必須）
`POST /internal/meshi-notify`

お店が追加されたとき、指定チャンネルに投稿してほしいです。

リクエスト本文（JSON）
```json
{ "embed": { "title": "店名", "url": "https://…/?s=店ID", "description": "コメント", "fields": [], "author": { "name": "○○さんの新しいおすすめ" }, "timestamp": "2026-11-18T01:15:01.403Z" } }
```
- BOT側は `embeds: [embed]` で送信し、`allowedMentions: { parse: [] }`（メンションは飛ばさない）にしてください
- 応答: `200 {"ok":true}` / `401` 署名不正 / `409` 再送 / `502` 送信失敗
- 実装例（Express + discord.js）は、添付の `lumi-relay-snippet.js` に書いてあります

### 2. メンバー確認（あると助かる）
`GET /internal/members/:discordUserId`

サイトの投稿を「サーバーのメンバー（または特定ロールの人）だけ」にしたいです。今はDiscordのOAuthで、参加サーバー一覧から判定しています。BOT側で確認できれば、ロール単位の制限もできます。

応答例
```json
{ "member": true, "roles": ["ロールID", "…"], "joinedAt": "2025-01-02T03:04:05.000Z" }
```
- 見つからないとき: `404`
- 取得するのは、ID・ロールID・参加日だけ。ニックネームやメールなどの個人情報は不要です

### 3. 活動ランクの取得（あると嬉しい）
`GET /internal/users/:discordUserId/rank`

Lumi系の活動ランク（発言数など）を、サイトの投稿者名の横にバッジとして出したいです。

応答例
```json
{ "messages": 320, "rankRole": "常連", "rankRoleId": "ロールID" }
```
- 登録のないユーザーは `404`

### 4. 投稿数に応じたロール付与（任意）
`POST /internal/roles/grant`
```json
{ "userId": "Discord ID", "reason": "ご当地めし帖で5件投稿" }
```
- 付与するロールは、BOT側の設定で固定（リクエストで指定させない）
- すでに持っているときは `200 {"ok":true,"already":true}`
- ロール名は「グルメ」のようなものを想定していますが、BOT側で決めてください

## サイト側が用意するもの（BOTから使える）
- `GET /api/spots` … 全お店の一覧（認証なし。店名、場所、ジャンル、口コミ平均、いいね数、位置を含む）
- `GET /export.kml` / `GET /export.csv` … 書き出し
- 通知のリンク `https://…/?s=店ID` … 該当の店に直接移動
- BOTのスラッシュコマンド（例：`/めし 県 市`）から、上の `GET /api/spots` を使って検索結果を返す使い方もできます。コマンドの実装はBOT側のお願いです。必要ならサイト側に、絞り込みつきの検索API（`?pref=&city=&genre=`）を足します。

## 相談したいこと
1. LunaBOT の技術構成（言語、Webサーバーの有無、公開URLの有無）を教えてください。内部APIの置き場所と呼び出し方を、それに合わせます。
2. 上のAPIのうち、すぐ出せるものと、難しいものを教えてください。まずは 1 だけでも始められます。
3. 署名用のシークレット（16文字以上のランダム文字列）は、双方の環境変数に入れる形で共有したいです。
